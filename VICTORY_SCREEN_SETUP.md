# Настройка Victory Screen (Экран победы)

## Где находится настройка

Экран победы настраивается в компоненте **CastleUIManager**. Найдите GameObject с компонентом `CastleUIManager` в вашей сцене.

## Способ 1: Автоматическая настройка (рекомендуется)

Система автоматически создаст экран победы, если он не назначен:

1. Найдите GameObject **"UIManager"** (или создайте новый GameObject)
2. Добавьте компонент **CastleUIManager** (если его нет)
3. В инспекторе в секции **"Victory Screen"**:
   - **Victory Screen** - можно оставить пустым (будет создан автоматически)
   - **Victory Sprite** - перетащите сюда спрайт картинки победы (опционально)

Система автоматически:
- Определит, используете ли вы Canvas или SpriteRenderer
- Создаст необходимые UI элементы
- Настроит обработку кликов

## Способ 2: Ручная настройка

Если хотите настроить вручную:

### Для Canvas версии:

1. Создайте новый GameObject **"VictoryScreen"** внутри Canvas
2. Добавьте компонент **VictoryScreen**
3. Настройте параметры:
   - **Canvas** - перетащите Canvas из сцены
   - **Victory Image** - оставьте пустым (создастся автоматически) или назначьте Image компонент
   - **Victory Sprite** - назначьте спрайт картинки победы
   - **Auto Create UI** - должно быть включено
   - **Use Sprite Renderer** - должно быть выключено

### Для SpriteRenderer версии:

1. Создайте новый GameObject **"VictoryScreen"** в сцене (не на Canvas)
2. Добавьте компонент **VictoryScreen**
3. Настройте параметры:
   - **Canvas** - оставьте пустым
   - **Victory Sprite** - назначьте спрайт картинки победы
   - **Sprite Size** - размер картинки в мировых единицах (например, 8x8)
   - **Auto Create UI** - должно быть включено
   - **Use Sprite Renderer** - должно быть включено

## Параметры Victory Screen

### В CastleUIManager:

- **Victory Screen** - ссылка на компонент VictoryScreen (опционально, создастся автоматически)
- **Victory Sprite** - спрайт картинки победы (будет показан при победе)

### В VictoryScreen:

#### Store Links:
- **Android Store Link** - ссылка на Google Play (по умолчанию: Hero Wars)
- **iOS Store Link** - ссылка на App Store (по умолчанию: Hero Wars)

#### Для Canvas версии:
- **Canvas** - ссылка на Canvas
- **Victory Image** - Image компонент для картинки (создается автоматически)

#### Для SpriteRenderer версии:
- **Victory Sprite** - спрайт для показа
- **Sprite Size** - размер в мировых единицах (X, Y)

#### Settings:
- **Auto Create UI** - автоматически создавать UI элементы
- **Use Sprite Renderer** - использовать SpriteRenderer вместо Canvas (определяется автоматически)

## Как работает система

1. Когда все монстры побеждены, вызывается `CastleUIManager.CheckVictory()`
2. Система проверяет количество активных монстров в `MonsterSpawner` или `MonsterSpawnerUI`
3. Если активных монстров = 0, показывается экран победы
4. При клике/тапе на картинку открывается магазин приложений:
   - Android → Google Play Store
   - iOS → App Store

## Подготовка спрайта

1. Создайте или импортируйте картинку победы в проект
2. Установите тип спрайта: **Texture Type** = "Sprite (2D and UI)"
3. Нажмите **Apply**
4. Перетащите спрайт в поле **Victory Sprite** в CastleUIManager или VictoryScreen

## Тестирование

1. Запустите игру
2. Убейте всех монстров
3. Должен появиться экран победы
4. Кликните/тапните на картинку
5. Должен открыться браузер/магазин с Hero Wars

## Отладка

Если экран победы не показывается:
- Проверьте, что `CastleUIManager` существует в сцене
- Проверьте, что `MonsterSpawner` или `MonsterSpawnerUI` существует
- Проверьте количество монстров (`monsterCount` в спавнере)
- Смотрите логи Unity Console для сообщений

Если не работает клик:
- Для Canvas: убедитесь, что на панели есть Button компонент
- Для SpriteRenderer: убедитесь, что есть BoxCollider2D на VictoryPanel
